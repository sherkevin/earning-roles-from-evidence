**对当前候选的约束。** 任务决策应先定义相对于某个可执行替代者/独做方案的增量任务质量和**完整系统成本**，而不是“交付内容正确”的绝对概率。真实接收者的 `accept/use/repair` 是选择后观测，不能直接当作交付因果贡献；受选择门控、评价者能力和后续独立复核影响。若用少量随机或配对重放给其校准标签，必须计全部重放开销，并与同信息的情境 bandit、Meta-Team 和式(20) 类审计预测基线比较。现有 AppWorld 单例的可见/隐藏两臂都在审阅额度处删失，**尚无**一条可评价的边际效用记录，更无角色形成证据。
