# Selected-only RLS 校正实验记录（2026-09-24）

该实验只用于检验事件协议和在线参数更新方向，不是论文最终 benchmark。环境随机生成 regime、菜单排列和 1–8 步反馈延迟；learner 只收到已选候选的反馈。隐藏 truth/未选 label 只存在于评估日志，未进入更新。

OnlineRLS 相对 uniform static 的 paired 提升为 +0.00711，12 个 seed 的近似 95% 区间为 [0.00392, 0.01029]；label-shuffle 为 -0.00055，区间 [-0.00241, 0.00131]。这与该构造环境中存在小幅反馈收益一致；打乱组没有可辨别提升，不能将区间跨零写成“信号确定消失”。

## 不能从这次实验推出的结论

- static 是 uniform policy，不是已经训练好的 Laya/AnyJev 静态 scorer，因此不能声称击败现有 JEV。
- 未包含 Beta、周期性 full-refit、contextual bandit 等全部强基线，也没有真实 peer/tool 数据。
- 评估使用了模拟环境的隐藏 truth 计算 counterfactual reward；它没有泄漏给 learner，但仍不能替代真实终端标签。
- 还没有测 A800 上 RLS 的 p50/p95；已有 A800 记录只测 gated scorer/update 的运行时吞吐。

下一步先关闭下述设计与复现问题，再选择资格明确的真实 selected-only 小回放。RLS 的效果不能代替新训练方法的创新性论证；本实验不触发扩量或方法冻结。

**我的算术：**对固定的 12 个完整 seed 做 10,000 次配对 bootstrap 重采样，随机种子为 20260924；每次抽取的是整条环境流，不把同一流内的事件当独立样本。以下是事后探索性区间，无多重检验修正，不能升级为预注册确认结论；和前表的正态近似区间是不同算法。

| RLS 相对 uniform static 的指标 | 平均差，百分点 | bootstrap 95% 区间，百分点 | 正/负/平 seed | 能说明什么 |

## 原始记录：对账通过，覆盖有限

分析脚本校验了 23,040 个 decision 和 23,040 个 feedback，一一核对选中候选、原始选择概率、到达步和延迟。四种方法各有 5,760 个 decision/feedback，二值奖励均值与聚合结果一致，未发现重复的 `(method, seed, source_t)`。

**我的算术：**RLS 与 uniform 在共用随机数的轨迹上仅有 7.5% 的动作不同；其已选动作概率范围为 0.1343–0.3937，中位数 0.2513。逆概率权重上限为 8，现有记录没有触发这个上限，因此不能用此结果证明截断机制的稳定性。

static 和 no-feedback 走的是同一个 uniform 分支，同样的随机种子得到完全相同的动作和分数。后者没有增加一个独立对照；下次应保留同一 scorer 和探索机制，只关闭标签更新。

RLS 有 54 条反馈在最后一次决策之后才更新。最终参数更新计数包含这些尾部反馈，不能用全部 5,760 次更新推断它们都影响了已报告决策；事件审计验证的是记录内部一致性，不能替代输入隔离的代码审查。
