# 四格消融的收益解释 — 2026-10-08

**目的：** 让论文能够区分“看到了更多评价”和“在线训练改善了分派”。这是对既有四格设计的展开，不是更换方法、benchmark 或验收标准。

## 问题与修订

旧稿列出无证据/无更新、仅证据、仅更新、证据+更新，却没有定义各比较支持什么结论。若完整方案仅胜过无证据/无更新，即使更新本身毫无作用也可能得到这个结果。

新稿用 `V_eu` 表示四种条件的未来分派效用，给出三个次级解释量：完整方案减仅更新，是在学习器中加入公开评价的作用；完整方案减仅证据，是在证据输入已有时增加训练更新的作用；四格差分给出既定效用尺度上的交互项。它们不取代已有 H1–H4 主终点，也不被包装成新算法或性能定理。

实例保持真实含义：A 对 B 的评价可以通过输入影响下一次选谁，参数不必改变。只有后来任务被实际执行、收益规则通过、更新完成之后的再次执行，才能检验参数更新的额外作用。接收方自己的工作仍不能记成产出方错误。

新增四行结果表只预留未来效用及流级 95% 区间、完整成本，共八个未测格；破折号明确表示未运行。它不恢复此前九行执行元数据与结果混排的大表，不填预测数字。

## 对照规范

- 四格使用同一起始条件、外部任务安排和预声明质量—成本规则，各自保留独立真实历史。
- 公开评价开关影响选择器输入，不删除审计事件或绕过责任检查。
- 关闭更新时持久参数不变；评价作为新输入仍可改变选择。
- 消融有意改变信息可见性，不能称为主结果的同信息比较；后者仍需独立强 baseline。
- 固定历史的分数重放只诊断输入敏感性，不能估计在线效用差。
- 以独立流而不是单次交接作为不确定性单位；收益规则、UNKNOWN 处理和实际成本仍须在调用前冻结。
