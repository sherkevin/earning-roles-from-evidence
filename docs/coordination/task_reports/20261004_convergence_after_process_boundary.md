## 审计目的与衡量指标

本任务不新增算法、不启动 API/GPU，只把 2026-10-03/04 的 peer-history append、四格 projection consumption、scope 修正和跨进程恢复回执映射回当前唯一生效的三份验收标准。通过条件是：每份标准都明确列出已关闭门、未关闭硬门、证据路径和下一项单一动作；不能把工程 qualification 记成科学结果。

## 三份标准的当前状态

### 故事线与创新点：`NOT_READY`

已具备：故事的责任链仍是 `真实交付 → recipient situated judgment → attributable producer evidence → future assignment → later quality/cost`；recipient-owned repair、UNKNOWN、source/target lineage 和 candidate scope 的错误归因已被保护性停止；历史 projection 已能改变一个测试 selector 的 propensity。

未具备：没有真实独立 recipient judgment→future assignment→未见任务质量/成本的闭环；没有证明 peer suitability、专业化或自进化；创新仍是待验证的“责任感知 evidence 与延迟更新组合”，不能在摘要/正文写成已证实收益。单条非法 arrival-order 负例也不等于真实多条历史置换鲁棒性。

结论：故事切口保持 sharp，但因果链仍缺 live evidence；不降级 Goal，不提前锁定贡献措辞。

### 方法论：`NOT_READY`

已关闭的工程门：delayed credit 后的 canonical history append、exact credit digest、assignment/read-cut/arrival binding、snapshot/replay、未知 version/digest/truncation fail-closed、目标 role/state scope 过滤、history/no-history matched selector consumption。正式零调用回执均记录成本和 UNKNOWN。

未具备：最终 backbone/updater 未锁定；history 尚未跨真实 episode 被持久消费；projection provenance/receipt 仍不是 selector 可独立验证的认证边界；没有 selected-only 每条反馈的实时 p50/p95、漂移响应窗口、旧任务遗忘和完整成本；没有 policy update 与 later-use 质量结果。当前 selector 是 test comparator，不能称最终方法。

结论：方法合同的责任和状态边界更可执行，但 ER-G2 的实时性、时效性、稳定性和自有在线训练创新仍为 OPEN。

### Benchmark + baseline：`NOT_READY`

已具备：主轨仍明确为 TeamBench-derived `PeerRoleBench-TB`/ArtifactRole 候选，副轨与主轨分开；PIPE3 可以承载 canonical source→target fixture，失败和 UNKNOWN 有原始回执；baseline 矩阵仍包含 uniform/no-update/raw acceptance/terminal-only/contextual trust/pooled/RARE 及 RLS/SGD/refit comparators。

未具备：第二结构独立 root 与 authority 尚未冻结；当前四格和跨进程都是同一 CPU fixture；七 arm same-information live parity、独立 history、later-use precision、完整成本和 confirmation split 均未运行；因此 benchmark 仍是候选，baseline 仍是设计而非比较结果。

结论：选择方向没有被新回执证明或推翻；不能开正式效果流或 A800。
