# Task report — Guide 置信度审查与联合分布重建

日期：2026-10-08。状态：`CONDITIONAL_GUIDE_COMPLETE / EMPIRICAL_FORECAST_OPEN`。
Goal 变更：false。0 新 API、0 GPU、0 新 benchmark 实验。

## 目的与衡量标准

回应用户要求：预期矩阵需要逻辑自洽，同时让科学家对标指标的共同分布与误差。
本任务要求同人群、同来源的五指标联合分布；有限样本误差可计算；协方差与费用关系
一致；独立审查；逐页水印；历史版本保留。现实效能预测还必须有合格真实流拟合
和留出检验，不能以模型计算准确来替代。

## 发现的原因

v1 的方法均值与误差主要是人为目标，没有共同拟合的选择—结果—费用过程。
平衡风险人群与选择后的评价人群关系不清，假定的 SD 也未由真实独立流估计。
先前审查检查了目标标识和局部算术，没有充分检查联合分布与现实预测置信度。
这属于本任务应纠正的不足，不能拿“只是目标”作为忽略分布的理由。

单 root 八次真实 API 调用仍只支持调用与个别更新事件的来源核查，没有更新后实际
任务、独立方法未来历史、校准人群、漂移或尾延迟分布。因此真实方法排序和误差
目前不可识别。v1 不再作为效果预期依据，但旧 PDF/源码/计算保留不改。

## 实际改进

v2 使用明确的冻结策略条件模型：候选潜在质量与选择概率共同决定选中 Y；同一 Y
驱动 Brier/ECE、失败返工费用和效用，费用扰动有明确离散分布。对三种二项计数与
扰动计数精确积分，计算均值、SD、边际预测区间、区间概率质量和五指标协方差。
没有生成虚构 agent/API 观察，也没有把真实方法绑定到有利的情景参数。

S3 情景 Q=.6，Brier=.2125，population ECE=.05；30 次 iid 观察的 sample ECE
期望为 .0999487。费用期望 .946667，效用期望 .505333。质量流 SD=.089443，效用
流 SD=.095423，五个边际区间内模型概率均≥.95。Q–U 相关为 .9998；它们不是独立
指标。这些数仅在未拟合的参数条件下成立。

配对敏感性另说明：相同 ΔQ=.05，候选潜在结果耦合不同会使 30 次观察的配对效用
SD 从 .0425 到 .0682。再加入 root 差异与流内相关，规划区间可以越过零。
它是近似规划敏感性，不能伪装同一精确分布或现实 CI。

逐流对标模板要求记录预测版本、合法分母、实际值、误差、区间成员资格、UNKNOWN
和失配来源。κ/u 不可仅由 selected-only 标签均值识别；真实自适应实验优先拟合
可观察的流级联合分布与差值，不补造未选候选结果。
