## A0：closest published adapter

**决定：严格 ArtifactRole 主矩阵为 `NO-GO`；保留 Meta-Team L2-style 为候选 adapter，
不计入已通过的 published baseline。**

依据：

- Meta-Team 原生 L2 使用交互轨迹和终局结果更新 teammate profile，信息边界、责任归因、
  selected-only 分母和 later assignment 都与 ArtifactRole 主轨不同；直接搬用会扩大信息
  集，不能作为公平比较。
- 本地代码锚点 `36dc85d9dc2219d292fa180f347479738a84acb2` 未发现明确 LICENSE/COPYING，
  因此不复制代码，也不把独立重实现称为 upstream reproduction。
- `20260930_metateam_public_profile_qualification.md`、assignment offer/runner binding
  和 PIPE3 replay 回执只证明 public profile schema、watermark、offer lineage、assignment
  顺序和隔离接缝可构造；没有证明 profile 摘要质量、closest 语义 fidelity 或科学效果。

允许继续做的工作是 `MetaTeam-L2-public` 的独立 adapter qualification：只读公开
delivery→recipient judgment/use/repair→arrival/correction，固定摘要规则、调用预算、
profile capacity、snapshot/restore 和 profile→assignment 映射。若其中任何项不能预注册
并通过 independent history，则永久保持 NO-GO；不能以手写 trust score 代替。

## B0：第二 structural root

**决定：PIPE3 保留为 development/primary candidate；PIPE2 保留为 derived candidate，
暂不作为 confirmation root；MULTI3 不进入主矩阵。**

- PIPE3 具备当前最完整的 producer→recipient→adoption/terminal→assignment 接缝，但
  真实 independent live history、later-use、公开 judgment 质量和完整成本仍未完成，因而
  仍不是已冻结 benchmark。
- PIPE2 的 extract→transform→load 结构确实不同于 PIPE3，适合作为潜在第二 root；但 pinned
  generator 的 seed `1,4,6,9` 存在未转义 CSV 字段，完整 root fixture validity gate
  失败。CSV-writer overlay 产生了新的 derived digest，尚未证明保留上游任务语义或拥有
  独立 authority。valid seed 子集不能事后升格成独立 root。
- MULTI3 native scorer/fixture 依赖 hardcoded oracle 和 shared schema，已被保留为
  `CONDITIONAL-LOW` fallback，不承担 confirmation claim。

## 对三份验收标准的影响

- **benchmark 选型**：仍 `NOT_READY`。A0/B0 消除了两个模糊占位，但没有完成 authority、
  independent root、later-use、power/precision 或 clean replay。
- **baseline 选型**：closest published 明确 NO-GO；strong same-information comparator
  已有 `contextual_trust_linear` CPU candidate，但尚未进入 active manifest 或 live parity。
- **实验矩阵**：不能把当前七臂 offline replay 当科学矩阵。下一道门必须运行独立 policy
  namespace，并让 chosen candidate 独立生成 delivery、recipient action、adoption 和 later
  outcome；不能共享一份已生成 outcome。
- **Goal**：没有任何降级请求；失败原因是证据和 benchmark authority 不足，不是降低标准的
  理由。
