# 任务条件选择：表示反例与候选对照

日期：2026-10-08。状态：`CANDIDATE / NOT_LIVE_INTEGRATED`。阶段：M/R。

**要解决的缺口是：任务变化后，Agent 的相对适合程度应能变化。** 本卡补强同信息线性对照，保留用户提出的画像相似度路线。最终方法、encoder、合法收益和创新结论仍未锁定，不修改六份 ACTIVE 文档及 Goal。

## 1. 最少输入与实例

沿用 [收益卡](route_utility_and_scoped_judgment_v0.1_20261007.md) 的执行前上下文 x、候选 a、实际后续收益 u。

| 量 | 来源、实例及代价 |
|---|---|
| x | 当前任务、责任角色和接收方条件；例：公开 PIPE3 producer→processor 合同，加执行前已知接收方身份/版本；不是 target J/Y |
| z=f(x) | 冻结 encoder 的向量，范数不超过1；代数例 z₁=(1,0)、z₂=(0,1)，仅为手算坐标，不是模型输出；本地 MiniLM 候选输出384维但需检查文本覆盖 |
| a、eₐ | 精确 candidate@version 与其固定注册坐标；如 peer-b@v1。菜单位置不是身份 |
| u | 后续独立质量与预注册成本规则得到的 signed route utility；本轮代数例 ±1 为人工数值控制，不是任务实测标签 |
| hₐ（仅画像候选） | 当前 read cut 前已经发布的有类型经验文字的冻结 embedding；新增输入需付画像构建/刷新成本，不能把 noisy J 直接写成已证能力 |

## 2. 为什么拼接不够

冻结一个线性头，拼接任务与身份后的候选差值为：

$$
s(x,a)=w_z^\top z(x)+w_a,
\qquad s(x,a)-s(x,b)=w_a-w_b.
$$

Case：序列化任务应优先 A，队列任务应优先 B。无论 z 怎样变，上式 A/B 差值固定，因此不能同时表示这两个严格排序。这一结论只约束该线性头：独立的上下文 base score、非线性 reranker、不同菜单或不同时间的参数仍可能改变最终选择，不可扩大成整个系统必然不看任务。

## 3. 最小可计算修正

为每位候选保留一组任务权重，相当于用固定身份与任务作交互：

$$
\phi(x,a)=e_a\otimes z(x),\qquad
s(x,a)=\theta_a^\top z(x).
$$

Case：A 的参数为(1,−1)，B 为(−1,1)；z₁时选A，z₂时选B。两个任务向量在两位候选间共享，差异来自已选路由的历史收益。仅更改 context_key 字符串而实际输入同一 z，仍不能表达这一区别。

使用 [signed ridge](signed_ridge_comparator_v0.1_20261008.md) 的同一正则 ρ：

$$
\min_{\{\theta_a\}}\sum_a\left[
\rho\|\theta_a\|^2+\sum_{i:a_i=a}(z_i^\top\theta_a-u_i)^2\right].
$$

Case：四个独立控制行依次观察 (A,z₁,+1)、(B,z₁,−1)、(A,z₂,−1)、(B,z₂,+1)，ρ=1时 θ_A=(.5,−.5)、θ_B=(−.5,.5)。每行仅给当次已选候选一个值，不从一次任务推导未选 Agent 的标签。

交互特征的不同候选块互不重叠，所以大方程严格分块：

$$
A=\operatorname{diag}(A_1,\ldots,A_K),\quad
A_a=\rho I+\sum_{i:a_i=a}z_i z_i^\top,\quad
b_a=\sum_{i:a_i=a}z_i u_i,\quad A_a\theta_a=b_a.
$$

Case：K=2、d=384时，不必每次解768维方程；反馈属于B就只解B的384维方程，A原样保留。稠密求解更新从朴素 O((Kd)³) 降为 O(d³)，数组存储从 O(K²d²) 降为 O(Kd²)，全部候选打分 O(Kd)。这只是经典可分离计算，不声称新推导或已实现系统实时性；Python开销、encoder、存储和合法标签验证另计。

这一基线对应经典 disjoint 线性模型的回归部分，来源见 [原文](https://arxiv.org/html/1003.0146v2) 与 [代码复用核查](../../../revision/CODE_SURVEY_contextual_ridge_20261008.md)。未实现 UCB 时不命名为完整 LinUCB。

## 4. 画像相似度如何保留、如何融合

| 候选 | 表示与作用 | 限制与最小反证 |
|---|---|---|
| A：独立任务权重 | eₐ⊗z；已见 Agent 的任务条件回归 | 新 Agent 无共享权重；相似文本不保证相似执行难度。做未见任务和新 Agent 对照 |
| B：画像双线性 | z⊗hₐ；共享任务–画像匹配 | 相同画像不可区分，画像错误可负迁移。做画像置换/同画像不同结果对照 |
| C：共享画像加身份残差 | 拼接前两种交互，分别正则 | 容量更大、样本稀疏时过拟合。必须与A/B同信息同预算比较，不能仅比弱one-hot |

画像相似度正是双线性模型的一个特例：

$$
s(x,a)=z(x)^\top W h_a,\qquad W=I\ \Longrightarrow\ s=z^\top h_a.
$$

Case：任务和“曾在某种任务中交付被实际采用”的带范围描述用同一384维编码，单位向量内积就是cosine。训练W可调整哪些任务–画像关系更预测真实收益；但完整W有147,456个参数，其普通完整ridge Gram含21,743,271,936个元素，float64约162 GiB，**不能直接复用小head的低成本结论**。低秩/固定投影需另作候选并验证；本轮不实施B/C，不把它们的新名字当创新证明。

最小实施选择是A作为对照基础，不是放弃B/C或冻结主方法。本文创新仍须来自可证的 situated judgment 使用机制及未来任务收益，不能由上述经典特征变换替代。

## 5. 防止“能算”被误认为“能泛化”

- 固定 encoder/schema；每次决策保存当时的 z、画像版本与 read cut。延迟标签使用封存旧向量，不按后来的画像重新编码过去。
- 画像内容变化若仍用同一 encoder，是输入随时间变化；更换 encoder/投影则是坐标变化，旧参数不能直接沿用，需预注册迁移或重建。
- 新目标的 J/Y 不进入当前 z；纯 task-only A 不包含 public memory，不能被说成已满足完整 same-information 比较。正式对照还需相同可见经验输入。
- selected-only、正概率支持、缺失机制和未来执行仍要验证。状态更新不证明反事实收益；条件向量不足时，回归学到的关联也不等于 agent 能力。
- 本轮数值控制只验代数、顺序与隔离；本地 encoder 检查只验输入覆盖/可运行性。0/1/K-shot、跨root、漂移、遗忘和创新验收均仍待真实证据。

## 6. 独立讨论与保留意见

Codex审查者确认了可加线性反例、分块修正和画像泛化边界。实现审查发现现有C1只有选择摘要，没有保存完整可恢复特征；不能回填历史sidecar冒充当时已封存。主维护者采纳A的候选数值实现，保留B/C为同一实验设计中的后续比较方向。

下一可执行步骤是补**真实决策时**的上下文封存与选中收益通道，而非重复运行同一身份特征实验。完整cost/λ、自然判断支持度、benchmark split和新API预算的现有缺口不因本卡消失。

## 7. 本轮实际检查与结论

两次审计均有22项定向测试通过；独立分块参考、交叉偏好、候选重排/子集及版本隔离均通过。四行人工控制中，identity/additive均给0分，disjoint在两个任务上的A/B分数分别为(.5,−.5)/(−.5,.5)。这些是构造的表示反例，未测任务成功率或样本效率。

本地真实冻结模型推理（CPU）发现：MiniLM 对四份公开合同/角色文本中的两份截断，输入长度467而限长256；丢失部分 C4、全部 C5/C6 及末尾要求。保留该失败后，已缓存 BGE-small-en-v1.5 的原生512长度覆盖四份输入（226、226、467、467）。这只通过文本token保留检查，未证明模型理解责任、完整路由上下文或效用；不锁定backbone，不继续比较更多encoder。

真实BGE float32归一化输出转float64后，3/4向量范数略大于1，不能直接交给严格的数值核心。离线适配检查显式采用float64 L2归一化再乘固定半径 `1−1e−12`，保留原始向量与转换后的向量及摘要；四个向量被未训练的回归组接受，更新数为0。这个事后适配不等于真实selection时的封存。

完整证据见 [v1](../../../experiments/logs/n03_contextual_ridge_20261008_v1/) 与 [v2](../../../experiments/logs/n03_contextual_ridge_20261008_v2/)，主维护者的 [任务报告](../../coordination/task_reports/20261008_task_conditioned_comparator.md) 映射回三份标准。科学gate保持关闭。
