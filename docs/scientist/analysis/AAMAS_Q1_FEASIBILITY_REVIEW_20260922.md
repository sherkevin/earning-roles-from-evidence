# Q1：真实实验后的方法取舍

2026-09-22。基于一次独立只读审查及本轮真实实验。
这是对 [Q1 v6.1](AAMAS_Q1_worker_differences.md) 的方法可行性判断，
不建立新的执行计划；要求与状态仍以两份项目主文档为准。

## 判定

**不锁定 v6.1，不提升本轮六份经验候选。** 真实调用已经证明实验基础设施
可用，但没有证明有用的新增能力、更新与消费者的交互，或更便宜的可迁移
资格检查。完整 dev 普查只判断当前设置的改进空间，不能自动补齐这些证据。

普查最终因再次运输故障停在 38/57：33 个有效成功、2 个有效失败、3 个未知，
另 19 个未开始。全部已观察有效失败都完成审计；这个未完成结果不能给出
全体提升空间判断，原候选也不会因此获得晋级。

当前 Q1 选择的目标是减少因采用能力更新而付出的协作失败与测试成本。
在这个主张下，角色、经验和工作流需要实际改变更新采用决策。这个目标
不是原始研究唯一合法的切入口；条件互补、减少返工、同质量下的资源节约
也可能有价值，但需要各自明确的机制与证据。记录更多内容、形成更多角色、
添加更多检查，本身都不是贡献。

## 现有信息能够支持什么

公开代码和 API 观察加上合法训练终局布尔，能够支持一个条件经验筛选基线：
从来源明确的轨迹提出程序候选，在隔离的新训练实例上做旧版/新版完整任务
对照，保留旧版或采用候选，并记录全部成本。提案、修订、删除、按需使用及
NOOP 已有近邻方法覆盖，见 [一手资料审计](../../../references/aamas/acquisition_followup_20260922/README.md)。

这些信息不能直接提供：哪一个部件导致失败、独立局部能力是否提高、一个
公开条件是否充分保证下游用途、或不同新组合是否可以免于完整回归测试。
本轮 runner 也没有实际 producer→consumer 边界；不能把单代理中间变量
重新命名为两个角色，就算测到了协调问题。

| 决策环节 | 可以具体规定的规则 | 尚未解决的条件 |
|---|---|---|
| 记录 | 版本、真实边界、固定消费者、可观察条件、操作、来源步骤、测试、成本 | 当前不存在被实测的边界与消费者，不能伪造这些字段 |
| 提案 | 限定候选数量；仅使用公开字段、分页终止、ID 去重、读写依赖、执行回执；缺证据记 UNKNOWN，不能定位操作则 NOOP | 这只是候选语言的范围，尚不是已实现或证明足够的语法 |
| 测试 | 提案数据与资格数据隔离；固定顺序；新旧包从同一初始世界执行；全部调用计费 | 没有可靠局部标签时仍须完整 continuation，尚无成本优势 |
| 决策 | 当前晋级规则失败；保留旧版；缺消费者、局部质量或新包自身证据时 UNKNOWN | 不能添加事后阈值让现有候选通过；公开检查通过不等于任务合格 |
| 迁移 | 若后续可行，只先声称迁移到整个未见过的 producer package；固定消费者、边界、continuation 与任务分布 | 表示充分性是待检验假设，不同时声称换消费者、任务分布及工作流 |

这张表明确了可以做出的下一动作及缺失信息，**不是五项方法闭合已完成**。
当前允许的经验包动作就是保留旧版，候选留在待证池。若每一个新组合都要
重新完整测试，所实现的是回归筛选，不能称为可复用资格机制。

## 实际轨迹对简单解释的约束

第一轮文件压缩案例新增存在性检查与手动删除，请求从 15 次增至 26 次，
没有观察到避免失败的收益。它显示两次轨迹不同，尚不足以把差异因果归于
经验；无经验重复执行也存在行为和请求数波动，更不能据此断言能力改善。

dev 的两个已审计下载失败都验证了自己选定的集合。官方拒绝结果，公开轨迹
提示“喜欢”谓词作用对象有误，但任务语言歧义和因果修复仍需区分。因此，
有来源、ID 类型正确、执行后检查通过并不足以建立语义正确性。

已有训练代码正确取过“歌单中歌曲 ∩ 喜欢的歌曲”；归纳后的对象措辞却有
歧义。这提供了一个可研究的跨动作线索，尚没有干预后的迁移结果，也不是
新旧能力与伙伴的交互。见 [来源核对](../../../artifacts/experiments/aamas2027/dev_20260922/cross_action_scope_audit.json)。

[原生重放 fixture](../../../artifacts/experiments/aamas2027/replay_fixture_20260922/report.md)
进一步表明，数据库副本不等于完整执行状态。两次完整代码重放一致，仅数据库
恢复的续执行则缺少 REPL 变量，并触发退出异常。它是保留失败的部分验证；
今后的重放必须重建所需状态并付出成本，不能赋予方法免费反事实访问。

## 什么观察会终止当前机制候选

1. 预定范围内没有同时出现真实 acquired 更新、独立局部质量及实际消费者。
2. 固定条件表示给出相同检查结果，但受控的新旧包仍有可重复下游差异；这说明
   该表示不充分，不能无上限增添特征追逐结果。
3. 共同语义接口消除了差异，或每次仍需完整 continuation／专门补丁；此时
   未建立相对于强对照的可复用资格或成本优势。
4. 普查达到已有 floor／ceiling，则关闭该内容收益设置；UNKNOWN 使条件
   无法判定时，应报告不确定，不能自动扩样或寻找更弱模型。

这些是科研判断与既有规则的应用，不是新的普查门槛或追求正结果的适配。
普查停机状态及全部已观察失败的审计已经写回主任务表。

## 已经可以复用

真实 named-provider 执行器、原生状态/评分调用、冻结任务清单、完整成本账、
六份来源明确的候选、全部公开轨迹、失败审计与近邻实现资料已在本地。
它们能支撑强的条件记忆比较基线，也能减少下一轮基础设施重复工作。
目前没有证据把这些工程成果写成“学到了可迁移协作要求”。

## 报告判断的再次复核

2026-09-23，应用户要求进行两份新的独立只读审查，分别核对实验有效性与
科学结论范围。综合意见如下。它是作者侧复核、待讨论的建议，不是外部
同行评审，也不构成新的共识、方法冻结或实验协议。本次没有新增模型调用。

**保留：不晋级这份候选包，不锁定尚未具体化的 Q1 算法。修正：不能把
该包失败推导成经验学习无效、三项设定不成立，或必须先提高单代理成功率。**

| 判断 | 证据所允许的范围 |
|---|---|
| 六对最终评分都是 6/6 | 本次没有成功差异；其中一对存在未豁免运行缺陷。既未证明等效，也未证明经验普遍无效 |
| 至少两胜才晋级 | 这是继续投入的启发式；不是显著性判据，也不是 Q1 的逻辑必要条件。Q1 式 (2) 允许局部质量持平 |
| 经验改变行为 | 两侧轨迹有差异；无经验重复也会变化，尚未排除运行波动。即使确认整个提示包有效，还需区分经验内容、通用提醒和长度效应 |
| 经验使执行更贵 | 六对总请求 96→99、上下文 739,410→886,460，输出 14,968→13,430；方向混合，未知价格及复用次数，不足以断言长期货币成本 |
| 普查不完整 | 正确。33–55/57 是缺失结果的确定性界限，不是置信区间；已排除预定低成功率区间，但不能区分中间与高成功率区间 |
| 创新与近邻有重合 | 已知的归纳、修订、按需使用与协作反馈不能单独承担创新；并不证明不存在新的机制或可成立的实证发现 |

成本解释还需要两项限定。上下文增量主要是缓存读取（645,760→792,192），
未缓存输入为 93,650→94,268。六对中四对请求更少、两对更多；剔除不合规
的一对后为三对更少、两对更多。当前不能据此称有稳定效率收益。若把获取与
归纳的 102 次请求全部摊入这六次复用，首次使用开销明显增加；长期经济性
仍需预先定义复用次数和计价方式。924 次总请求代表执行工作量，不是独立
样本量；六对共享同一个经验包，同家族实例复用也不等于未见家族迁移。

原始 EMNLP [评审意见](../../../EMNLP2026-OpenReview-审稿意见汇总.md) 认可
核心构想值得研究，同时质疑解释不清、结果不稳定、调用成本、对照充分性
和适用范围。它们没有要求必须转向“更新兼容性”，也没有要求有限谓词或
严格的单代理准确率提升。这些属于后来选择的研究切入口，不能当作审稿人
已证明的唯一出路。旧实验的局限同样不会因新故事线而自动消失。

四项要求应分别绑定相应主张：独立局部质量用于识别“局部不差但协作受损”；
实际消费者用于测量下游交互；有限谓词是当前可解释学习器的设计选择；较低
资格测试成本用于支撑相对完整复测的效率主张。不能把它们捆成所有组织学习
的通用准入条件。强共同接口对照必须可执行、同信息且计成本，不能隐含
免费正确的语义理解。平均效果与分布内迁移也不要求先证明普适语义保证。

禁止通过造弱消费者、删除必要信息或事后选题制造优势，是合理的研究边界。
它不禁止事先设计有真实信息依赖和分工的多代理任务；各方法需要共享任务
结构、信息机会、接口和预算，探索后的确认数据应独立。当前 AppWorld 单
代理试验没有消费者，只说明该次试验没有测协调，不说明以后不得设计它。

当前最需要补齐的是研究问题、算法和测量的对应关系。原试验只运行一次性
六卡全量拼接，没有实现私有经验差异、证据驱动角色选择或工作流复用。
需要先明确输入产物、合法反馈、版本更新、采用与回退的具体决策规则，再
以同信息的共享经验、普通路由／匹配、完整回归筛选等最相关替代方案进行
比较。只要求定义清楚、能执行和被反驳；不要求先有正结果才允许预先冻结。

保留三项设定与宣称三者各自必要是两回事。现有证据不支持直接删除它们；
若论文主张其分别有效或相互强化，应使用相应冻结、交换、去除对照。当前
两个 dev 失败来自同一家族，而且没有接收第一轮经验，不能把归纳措辞歧义
说成它们的原因。后续远端 R1–R3 的事后原生重放已做受控干预，语义选择
加共同检查能修复这两例；一个同来源普通程序也逐项复现了结果。故这一
局部现象值得继续研究，但尚不是自主学习、未见分布迁移或独特协调机制的
证据。具体边界见[后续进展](AAMAS_REAL_ITERATION_20260922.md#2026-09-23远端后续进展不回写上面的旧实验结论)。
现有执行器、轨迹和记账可继续复用，冻结候选与本次失败记录保持原样。
