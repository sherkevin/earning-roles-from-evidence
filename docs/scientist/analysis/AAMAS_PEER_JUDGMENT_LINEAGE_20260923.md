## 转向之后的实测结果

- [旧 QA 重分析](../../../article/aamas2027/main.tex) §4：24,815 条头条预测的路由结果不是角色学习实验。HotpotQA 对所选基线仅 `+0.0045` F1，路由 token 约多 41.7%；2Wiki `+0.0857` F1。500 条组件实验里主动审计低于 task-tree 母体 `0.0081` F1，且有具体“记了拒绝标签却未落实控制动作”的失败轨迹。它们构成原方法改造的压力，不是同伴评判闭环的否证。
- [R0 实际 API 迭代](AAMAS_REAL_ITERATION_20260922.md) §第一轮：六个训练来源归纳的程序卡，在同模型单代理配对任务上官方结果 `6/6` 对 `6/6`，原定晋级门槛失败；329 次真实实验/归纳请求。没有独立 producer/consumer，也没有角色更新。
- [AppWorld 开发集普查](AAMAS_REAL_ITERATION_20260922.md) §第二轮：计划 57 项，传输故障后最终只尝试 38 项（33 个有效成功、2 个有效失败、3 个 UNKNOWN，另 19 个未开始；592 次请求），不能断定全体饱和或充分 headroom。两例有效失败给了谓词作用对象与下游语义检查的线索，而非同伴判断证据。
- [R1–R3 远端后续重放](AAMAS_REAL_ITERATION_20260922.md) §2026-09-23：R1 三臂各 `1/3`；R2 在事后固定、同家族三例上把语义选择加共同消费者检查做到 `3/3`；R3 同来源普通程序亦 `3/3`，复现选中集合、官方分数、数据库字节和环境 API 次数。局部交接错误和修复可观察，但没有独特机制增量，也没有在线多代理角色学习。
- 工作树中的 `artifacts/experiments/aamas2027/r5_repair_placement_20260923/` 尚未进入上述主账和审查，存在 `pending` 合同标记；不把它作为已闭合结论或原主线的检验。

## 核心创新究竟完善到哪一步

已经明确的**概念与识别修正**：角色是有语境的交付能力，而非自报、预设标签或全局一维分数；实际接收者的使用与返工比脱离任务的评价更贴近交付价值，但其验收也不是真值；要记录评判者、任务、依赖、执行包、成本和终局纠错；被评价者的角色证据与某委派者的私有信念必须区分。工作流可提供判断发生的依赖语境，私有经验可产生待识别的能力变化，但二者不能未经独立干预就同时宣称为新机制。上述认识已经写入 [决议 0005](../../user/decisions/0005-retain-peer-judged-role-learning.md)与[干净度自审](AAMAS_Q1_CLEANNESS_AUDIT_20260923.md)。

**尚未完成**：可执行的消费者判断→经校准的 `P_i` 更新；评判者误差、任务难度、选择偏差、策略性评价和责任归因的处理；该状态如何被合法传播并改变未来委派；真实独立 producer/consumer 的小批量测试；相对于任务型信任、[CADMAS-CTX](https://arxiv.org/html/2604.17950v1)、[RepuNet](https://arxiv.org/html/2505.05029v3)、[Meta-Team](https://arxiv.org/html/2605.29790v1)、原始验收率和同信息 bandit 的可测增量。因此现在只能称“保留的研究对象和更严格的假设”，不能称已经被证明的新算法或成功率结果。

历史判断：离开原主线的**压力是合理的**；把“不可信的全局 persona/普通 EMA”直接替换成工作流绑定/交接资格，是我们主动做出的过度收缩。后续实验没有证明应删除原主线，也没有替它补上算法与证据。
