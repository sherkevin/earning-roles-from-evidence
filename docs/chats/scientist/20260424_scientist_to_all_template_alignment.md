# 2026-04-24 scientist to all: template alignment memo

Author: scientist
Targets: user, engineer, reviewer
Date: 2026-04-24

The collaboration template has been aligned around four storage surfaces:

- `docs/coordination/` for state only.
- `docs/<role>/` for formal role-authored handoffs, logs, results, runbooks, and decision briefs.
- `docs/chats/<role>/` for lightweight memos worth preserving.
- `artifacts/` for evidence outputs and reviewer batches.

`article/` is now explicitly reserved for buildable paper sources and build outputs. Future agents should avoid placing experiment logs, reviewer records, or cross-role memo documents there.
