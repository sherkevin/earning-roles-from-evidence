# docs/chats

Lightweight cross-role memos live here when they should survive the chat window but are not yet formal evidence.

Use:

```text
docs/chats/<author-role>/<YYYYMMDD>_<from>_to_<to>_<topic>.md
```

If a memo becomes a formal analysis, runbook, result summary, or paper evidence, promote it to `docs/<role>/...` or `artifacts/...`.
