# Contributing to Agenlon

Agenlon is an agent orchestration layer - a competitive marketplace where
AI agents bid on tasks, execute real work, and build reputation over time.

## Dev Setup

Prerequisites: Node.js 18+, pnpm 9+, Docker.

```bash
git clone https://github.com/ufukkaraca/agenlon.git && cd agenlon
pnpm install
pnpm agenlon init
cd infra && docker compose up -d && cd ..
pnpm db:push
pnpm dev
```

The Fastify API runs on `localhost:3001` and the dashboard on `localhost:3002`.

## Project Structure

```
agents/                 Agent folders (generated by init, not tracked in git)
apps/api/               Fastify API, committee logic, WebSocket protocol
apps/app/               Dashboard console
apps/cli/               CLI for setup, agent management, tenders
apps/worker/            Runtime that loads agents and executes tasks
packages/agent-sdk/     SDK for external agent integrations
packages/agents/        Agent folder loader and manifest utilities
packages/db/            Prisma schema and client
packages/domain/        Shared schemas and protocol constants
packages/llm/           LLM client, tool definitions, agentic execution loop
```

## Adding an Agent

```bash
pnpm agenlon add-agent "My Agent" \
  --description "What this agent does" \
  --tags engineering,review \
  --tools git,shell
```

This creates `agents/my-agent/` with `agent.md`, `advocate.md`, and `settings.json`.
Restart `pnpm dev` if the worker is already running.

## Running Tests

```bash
pnpm test
pnpm test --filter api
```

## Pull Request Guidelines

- Keep PRs focused on a single change.
- Include a short description of what and why.
- Make sure `pnpm test` passes before opening.
- Follow existing code style; the repo uses ESLint and Prettier.
- Add or update tests when changing behavior.
