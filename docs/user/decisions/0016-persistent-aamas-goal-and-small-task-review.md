# 0016 — 持续推进 AAMAS 目标，每个小任务后复核方向

Status: Accepted. Date: 2026-09-26.

## 背景

用户接受 N00–N05 路线，要求持续推进，每完成一个小任务回头检查是否跑偏。
最终产出应让故事线、方法论、合适的 benchmark/baseline 和真实实验相互支持。
当前程序夹具已经检验部分协议，但真实角色学习收益和最终训练机制尚未成立。
用户同时要求开始题目和摘要，下载今年 AAMAS 的官方模板，以 LaTeX 写作。

## 决定

1. 为本任务建立持续目标：完成可复现、符合 AAMAS 科学及格式要求的论文研究
   和草稿。录用是努力方向，不能作为我们能保证的结果。
2. 保留 `learning roles from others' situated judgments` 为主问题；实时小型
   判断模型的训练服务于该问题，不能仅凭现成框架组合声明创新。
3. 按已登记的 N00–N05 小任务推进。每项结束在主任务台账记录：新增证据、
   是否推进主故事、仍不能得出的结论，以及继续/修改/停止本候选的理由。
4. benchmark 必须有真实交付依赖、合法信息边界和独立评分；baseline 必须
   包含同信息、同资源的强简单方法以及与最终机制最接近的方法。
5. 用户指定的 GPU 实验平台为星云 `damo_genomic_gene` 项目的 A800 队列。
   按已有约束直连、不走代理，一次只安排一个有资源上限、有判别价值的作业。
   新实验先冻结卡片，记录原始结果并复盘，再决定下一轮；不为利用 GPU 而训练。
6. 遇到真实阻碍先做有针对性的源码/文献/用户 vault 笔记查证，提取可复用
   组件；不能把无限调研、重复冒烟或增加模型数量当作项目进展。
7. 现在开始英文题目、摘要和 LaTeX 草稿；方法和实验未定的句子写成研究
   提案，并在 PDF 上标记内部 pre-results 状态。未测结果不写成论文结论。
8. 今年的模板按 2026 官方包保存；项目既定目标仍是 AAMAS 2027。核查官方
   2027 指南及模板后继续使用目标届次格式，不混用年份，不擅自改变投稿目标。

## 理由

最有价值的进展是减少一个会影响研究结论的不确定性。能运行、预测有信息、
未来分工有效、训练机制有创新、旧能力得到保留是不同层次，必须分别验证。
小任务后的复核将“做完了代码”与“支持了科学主张”分开，及时发现评测失真。
提前写摘要可暴露故事中的缺口，但不能反向选择数据以制造摘要希望的结果。

## 后果

- 持续目标已在当前 Codex 任务建立，状态为 active；没有新增固定周期通知。
- 状态唯一入口为 `docs/coordination/AAMAS_TASKS.md`，会话 todo 只保留指针。
- N00–N05 已获推进授权；任务资格失败不等于研究失败，须记录原因及可复用物。
- 不取代 ADR 0008 的条件性 benchmark 选择或 ADR 0012 的方法开放边界。
- 投稿、作者/评审承诺仍不在当前授权范围；当前为研究、实现、实验和内部写作。
