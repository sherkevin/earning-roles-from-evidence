# ADR 0038 — 决议文件治理与研究主线硬约束

日期：2026-09-28
状态：Accepted
范围：earning-roles 的决议文件、故事线、方法论、benchmark、baseline、创新点及后续论文工作

确认依据：用户在本次对话中明确提出本决议的管理规则、三项研究标准和应用场景；助手确认同意并据此归档。具体算法候选的效果和创新性不因归档而获得确认。

## Context

项目已经积累了多项关于故事线、方法论、benchmark、baseline 和创新点的讨论。若这些共识只留在对话中，后续任务容易发生任务漂移；若把临时实现问题或一次实验失败误当成研究结论，又会把尚未解决的工程问题误写成研究方向已经失败。项目需要一个可追溯、唯一、不可静默降级的决议机制。

此前的 0037 号决议已经记录了研究质量要求和“learning roles from others' situated judgments”主线。本决议在保留这些内容的基础上，补齐文件治理和双重确认机制，作为当前统一标杆。

## Decision

### 1. 决议文件管理

1. 所有正式决议放在 `docs/user/decisions/`（决议文件夹）中。该目录是本项目讨论后形成统一标杆的唯一归档位置。
2. 一项独立决议对应一个独立文件。文件使用连续编号和稳定的短标题，并在目录索引中登记；不得把互不相关的临时事项追加到同一个决议文件中。
3. 后续新增或修改的共识必须经过双方明确确认：用户确认内容，助手明确确认理解并同意后，才能将一致表述写入正式决议，并记录确认来源。助手自行提出的建议、审查意见和实验结果先放在研究文档或任务报告中；不将沉默、超时或一般性的“继续工作”视为对新决议的确认。
4. 如果后续共识实质性替代旧决议，必须新建更高编号的决议文件，并把旧文件标记为 `Superseded by NNNN`；不得抹去旧文件的历史文本。
5. 遇到抉择、无法决断、证据冲突或任务漂移时，先查阅本决议、`GOAL.md`、相关任务报告和更具体的 ADR，再决定下一步。每个小任务完成后都要记录：推进了哪条要求、仍缺什么、是否改变了已确认结论。

### 2. 故事线与方法论

故事线和方法论必须充分、合理、完备、自洽，并具有明确创新性；问题切口必须精确、sharp，能够把研究对象、因果关系、可观测信号、方法作用和评价结果连成一条可检验的链条。

当前保留的核心主线是：真实交付物被实际承担后续工作的 agent 在具体任务情境中判断和使用；这些可归因的 situated judgments 形成 producer 的 role evidence；evidence 被用于未来责任或角色分配；最终检验后续任务质量、稳定性和完整成本是否改善，即 **learning roles from others' situated judgments**。

实现困难、单次失败、数据不足或当前实验未通过，只能说明当前实现、测量或证据门尚未合格，不能自动把研究问题改写成更弱的问题。

### 3. Benchmark 与 baseline

Benchmark 必须足够合理，能够充分检验论文想证明的命题，并且必须公认、具有权威性。对既有 benchmark 的扩展要说明原任务语义、可比性及验证依据；使用权威来源不自动证明扩展后的版本满足本标准。必须明确任务契约、真实评分信号、信息可见性、数据划分、归因边界、失败/UNKNOWN 规则和停止规则。

Baseline 必须覆盖与主张直接相关的比较对象，并具备时效性、新颖度或经典性。每个 baseline 都要说明它控制的变量、公平性依据以及它不能回答的问题；不能因为某个 baseline 更容易接入就把它当成充分对照。

只有在 benchmark、baseline、评分信号、信息边界和停止规则都通过审查后，才能冻结它们并进入正式实验。工程接入成功不等于 benchmark 或 baseline 已经冻结。

### 4. 创新点

创新点必须立住，不能被轻易推翻，不能因为一个局部实现问题、一次实验失败或短期结果不理想就被悄然删除、替换或降级。应区分已确认的研究主线、已讨论的创新主张与尚未确定的具体算法机制；候选机制的失败不能直接等同于主线或整组创新点被推翻。

如果需要推翻、删除、替换或实质修改核心主线或创新点，必须先明确列出反证、反证针对的层次（问题定义、方法、测量还是实现）、替代方案以及对故事线和评价协议的影响，并与用户完成双重确认；确认后另写新的编号 ADR，旧 ADR 按替代关系归档。

发现反例或创新性疑问时，应如实记录证据并提交讨论。保留研究目标不等于宣称它已获证明，也不允许隐瞒负面结果。

## Consequences

0038 是本次治理规则与研究质量标准的统一入口；0037 保留为历史版本，其他决议继续按各自范围和状态适用。本决议不追认历史记录中尚未经双方确认的内容。后续任务报告和论文草稿必须按本决议逐条对照，并明确区分“研究主张尚未被证实”和“当前实现尚未合格”。实验失败需要保存、分析和修复，但不能被用作未经确认的目标降级理由。
