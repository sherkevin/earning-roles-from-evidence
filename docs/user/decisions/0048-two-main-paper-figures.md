# ADR 0048 — 正文收敛为两张互补方法图

日期：2026-10-07  
状态：Accepted  
范围：论文图组构成与视觉表达，不修改研究目标或科学验收门

## Context

用户检查当前三张 AI 图后指出：画幅太大、字体视觉重量过高、内容显得空，
三张图的质感不一致，与样例库仍有明显差距。用户明确要求继续生成提示词并绘制，
同时将正文图数从三张减为两张。助手接受这一编辑选择。

## Decision

正文保留两张互补图：Figure 1 结合责任混淆的具体反例与 earning-roles 闭环；
Figure 2 展开证据筛选、状态构造、未来选择与延迟更新的实现关系。
实验设计由完整实验矩阵和 baseline 表承载，不另占实验地图图位。

通过内置 AI 生图重绘，两图共用字体、配色、线宽与对象表达；每个提示词对应一个
版本和一张原图，保留历史版本。具体画幅和布局属于可迭代设计，不作为方法冻结。

## Rationale

图必须解释方法内部操作与因果边界，不能只把模块名放进框里。减少冗余图位给正文
和证据留空间；统一图组比独立优化三张通用流程图更有助于读者理解核心贡献。

## Consequences

- 当前有效图计划升级为 `FIGURE_PLAN_v3.md`，旧计划与三图资产保留。
- 新图须通过逐箭头语义、论文实际尺寸和样例对照检查后才替换活动资产。
- 图稿改善不构成方法效果证据；科学 gate、真实实验和 Goal 标准保持不变。
- 不在没有实验结果时绘制优势曲线、改善幅度或获胜标记。
