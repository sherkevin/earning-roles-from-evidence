# ADR 0054 — 数值回填时仅允许表格排版微调

**Date:** 2026-10-09
**Status:** Accepted by explicit user confirmation and maintainer adoption
**Scope:** 当前主 PDF 的预期数值回填与页数处理

## Context

用户要求把已有 expected 数值回填主 PDF 的矩阵和正文 xx，
其余文字不得修改。直接数值替换产生的候选保持原文不变，
但较长数字使正文由 8 页自然重排为 9 页。

助手提出两种处理：保留纯数字替换后的 9 页预览，
或允许微调表格排版以恢复 8 页。
用户明确选择：

> 允许微调表格排版以恢复 8 页，正文文字不变

## Decision

只替换存在明确来源且统计口径相符的数值位置。
允许局部调整表格列宽、字号、列间距与表格留白，
以恢复 8 页正文。不得改写正文、表头、图注、题目或公式来凑页数。

每项文字层面的差异必须属于原 xx 数值替换；
其他源文改动必须是表格范围内的排版指令。
保存回填前版本及逐项替换映射。

## Rationale

用户需要在保持论文措辞的同时查看数字进入全文后的效果。
局部表格排版微调可处理数值长度增加，
不授权叙事重写、方法修改或降低科学验收标准。

## Consequences

9 页初稿保留为历史候选，新版本通过 8 页检查后再同步主 PDF。
预期值预览继续明确标识 EXPECTED -- NOT OBSERVED。
此授权不把规划区间变成实测 CI，不授权给缺失指标编造结果。
未确定的数值仍保留，待指标澄清或真实实验后填写。

正文文字不变的检查与排版检查分别记录。
科学投稿 gate 不因本次回填关闭。
