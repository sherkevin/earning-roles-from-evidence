# ADR 0053 — 单一手写预期实验矩阵

**Date:** 2026-10-09
**Status:** Accepted by explicit user instruction and maintainer adoption
**Scope:** 预期结果参照的组织、版本与使用方式

## Context

用户要求复用合适的历史稿，最终交付一份干净的 expected experiment table，
与项目主 PDF 的实验矩阵一一对应。数值手工填写，不批量生成；有利情景应合理
体现优势，不利情景和成本应保留劣势，计算关系与跨表数值必须一致。
用户还要求修改后由独立子智能体审核，并保留历史版本。

## Decision

唯一当前数值对标 PDF 为
`artifacts/aamas2027/expected_experiment_matrix.pdf`。

其唯一版本指针为
`artifacts/aamas2027/expected_experiment_matrix_master.json`。
每次提升记录对应主 PDF 的哈希、表编号和行列映射。版本目录保留源文件、
数值、依据、审核和已生成的 PDF；旧版不再同时作为当前目标。

所有中心值必须由作者逐项选择。程序只能排版、计算定义性差值及复核，
不能生成模拟实验样本并把聚合值当成预测的证据。

预期表保持水印，并把预期范围与实际置信区间区分。真实结果可以与预期不同，
不依据这份表过滤、改写真实结果，也不把它复制为投稿的实证数据。

## Rationale

单一入口避免科学家使用不同的数值目标。逐表映射保证对标对象与正文一致；
手工数值、公开依据、数值验算和独立评审分别承担判断、约束、复核的职责。
预期表的合理性包含劣势、近似持平与不确定性，而非所有格子都让本方法获胜。

## Consequences

v5 为本次当前交付，基于 v4 及历史 contextual 数值修订；三张表对应目前
主 PDF Table 4/6/7。方向 Guide 仍是条件/验收参考，不是第二份数值目标。
修改数值或主稿表结构时须另起版本、记录理由并复核映射。

本决议不修改 Goal、三个科学验收标准或已有方法论决议。
预期表通过内部审查，不等于真实实验验收通过。
