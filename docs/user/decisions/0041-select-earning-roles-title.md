# ADR 0041 — 选择 Earning Roles 工作标题

日期：2026-09-29
状态：Accepted
范围：earning-roles 当前 AAMAS pre-results/proposal 稿件的标题与对外定位

## Context

旧标题 `Learning Roles from Situated Peer Judgments in Multi-Agent Collaboration` 能描述研究对象，但没有传达角色由协作证据获得、会随反馈变化，也没有留下足够的跨任务想象空间。候选标题经过用户和助手共同讨论，重点比较了动态性、自进化、自主责任形成、situated peer judgment 的可识别性和过度承诺风险。

## Decision

当前确认的工作标题为：

> **Earning Roles: Self-Evolving Responsibility from Situated Peer Judgments**

该标题用于 `research_proposal.tex` 和 `mainline_pre_results.tex`，并更新对应关键词。历史 `main.tex`/`supplement.tex` 属于旧 allocation/router 草稿，保持原样，不把新标题误写到历史稿。

## Interpretation boundary

`Earning Roles` 表示角色不是预设身份，而是通过交付、使用和反馈逐步获得；`Self-Evolving Responsibility` 表示研究目标是让未来责任随新证据动态调整；`Situated Peer Judgments` 保留核心证据来源。标题是研究定位，不是已经完成的效果声明。

在实时更新、旧能力保持、漂移恢复和 role-learning efficacy 尚未通过验收前，摘要、正文和结果表不能把 self-evolving 写成已验证结果。若最终实验不支持该表述，必须由用户和助手共同决定是否新建标题决议，不能因为失败自动降级或静默换题。

## Consequences

- 当前有效 pre-results/proposal 的题目和关键词统一。
- 论文后续摘要、引言和图表应解释 “earning” 与 “self-evolving responsibility”，避免被误读为普通 reputation 或 agent self-reflection。
- 该决议不改变故事线、方法、benchmark/baseline、Goal 或科学 readiness；这些仍按各自 active 文档和验收标准管理。
