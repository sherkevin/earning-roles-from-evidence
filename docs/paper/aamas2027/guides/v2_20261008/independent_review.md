## v1 主要拒绝理由

预期方法均值与误差缺少共同拟合的生成过程；平衡风险人群与选择后人群间未明确建模。
现有八次单 root 调用未识别未来方法效能、预测损失人群、方差或尾延迟，不能支持
高置信度的真实排序。局部算术正确和清楚水印不等于现实预测可靠。

## v2 首轮审查

结论：conditional-model guide 可 GO；现实方法效果预测为 `NOT_IDENTIFIED`。

审查员核验了候选数、成功数与独立 Rademacher 费用扰动的计数积分，五项指标均值、
SD、分位数与协方差。配对 D=.125、ΔQ=.05、ΔU=.05333，潜在成功耦合的可行范围、
方差式，以及 ICC/root 的方差式一致，没有重复除以 episode 数。

要求修正 S2/S3 Brier 的显示：两者同为 .2125，旧三位浮点格式却显示 .212/.213。
已统一四位。审查再次强调 oracle 情景、共享潜在结果与同 route RNG 只适用于冻结的
一阶段分析，不能自动套入独立的自适应方法历史。

## 修复后的复核

最终结论：**条件模型指南 GO；真实效能预测仍缺证据。**

复核确认 Brier 四位一致，Q–U 相关 .9998 没有显示成完美相关。S3 五项边际预测区间
概率质量为 96.1577%、95.1416%、95.9345%、95.2879%、95.1183%，展示的百分数与计算
一致。它们是指定离散分布内的概率质量，明确不是实测覆盖率。

审查建议增加逐 root/stream 的分布对标记录，检查留出覆盖、宽度及失配来源。已在
v2 PDF/说明与空白 CSV 中落实。管理者另补充：κ/u 不能由 selected-only 均值单独识别，
应优先拟合合法可观察的流分布，不能生成未选候选反馈。

该 GO 不支持真实排名、p95、漂移/遗忘效果、AAMAS 科学就绪度或验收通过。
