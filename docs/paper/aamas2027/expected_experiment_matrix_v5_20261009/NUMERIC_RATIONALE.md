## 公开量级资料：只借用可比的部分

已重新读取并存档五个原始网页，另复用 reasonable_results 中的原始论文核验。

- [TeamBench 固定资料](https://arxiv.org/abs/2605.07073)：本地先前核验中 native partial
  与二值 pass 分开；任务级单次值跨 .4167–1.00，旧仓库跨任务 partial 约 .55，
  但有模型来源和重评分冲突。这里只支持“部分质量在 .5–.6 并非量纲错误”的弱参考，
  不能拟合本项目 .608 或误差，也不能把 partial 当 60.8% 全部通过。
- [Meta-Team](https://arxiv.org/html/2605.29790v1)：Ansible 原生无演化 40.8%、完整
  53.9%、去 L2 50.7%；是不同协议的 pass rate。它支持区分整个系统和一个机制的贡献，
  不支持把 13.1 或 3.2 个百分点搬来当 RARE 预期增益。
- [DecisionBench](https://arxiv.org/html/2605.19099v1)：GAIA blind .407、C3 .393。
  多信息并不必然改善最终质量，因此保留强基线近似持平、负载/稀疏时反转。
- [Contextual Bandit Bake-off](https://jmlr.org/papers/v22/18-863.html)：简单 greedy
  可接近最强方法；因此 task-conditioned ridge、matched composition 的预测指标与
  RARE 很接近，不能用弱对照确立创新。
- [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)：risk 与 coverage
  联合报告；因此 .0066 必须与 .502 coverage 和 .01315 conditional risk 一起读。
- [Calibration](https://proceedings.mlr.press/v70/guo17a.html)：校准不同于辨别能力；
  Brier/log loss/ECE 是同一 Qp cohort 的不同指标，不拿 Brier 推导团队效用。
- [graph-IPD](https://arxiv.org/abs/2608.28977v1)：本地核验得到单人原生 reward 范围
  [-.3,.3]；副轨表明确使用 (r+.3)/.6。公开合作率、解析折扣回报、本地总回报
  均不能直接填这里。公开论文没有这里的服务延迟数字。

公开论文不给出同协议的 RARE 效应。上述数字参考与本表的主观预期严格分开。
最新网页及 SHA-256：experiments/logs/expected_experiment_matrix_v5_20261009/sources/。

## 每组中心值为何这样取

1. **主比较**：保留 v4 RARE .608 与历史 contextual .588。额外质量 .020 抵消
   .12 额外完整成本中的 .012，净效用只剩 .008。RARE 没有被设成绝对优势；
   pooled .472、RARE .474 也仅差 .002。成本差包含不同分工造成的执行/整合差异，
   不声称 16 ms 在线更新能解释 12% 完整成本差。
2. **四格**：沿用 .430/.448/.455/.474。与无证据相比，总增益 .044；单独信息
   .018、单独更新 .025，交互只有 .001。没有为了创新叙事把交互调大。
   删除 updater 与禁用持续更新是同一干预，均 .448，不再造另一个“去 updater”数值。
3. **预测**：RARE .203 Brier，比 contextual .211 改善 .008；比匹配组合 .206
   仅改善 .003；都允许平局。确认根 Brier .217 比开发/共同 cohort .203 退化 .014。
   这些多指标为可检验的联合预期，并非已经构造或拟合出的预测分布。
4. **服务**：采用 v4 的几十毫秒量级，并明确只计 CPU 上已有特征的反馈处理。
   手写 p50：history 18、context 29、RLS 35、SGD 31、periodic 28、RARE 37；
   p95 分别 32/52/66/64/120/68。周期拟合中位数快但尾部慢具有机制解释；
   不再按统一 .6 比例推出中位数。无更新时延在 JSON 是结构性 null，另有
   no-op dispatch 2.5/3.0 ms；这不是缺失实验占位，PDF 没有这些不适用的更新格。
5. **不利条件**：稀疏时 RARE .427 效用 < pooled .450；高负荷时 RARE payoff
   .542 < context .558，同时 p95 480 > 290 ms，丢弃率 .11 > .06。
   丢弃/超时计入所有 5000 arrivals 的 ITT，归一化 payoff 罚值 0。
   因此较高丢弃不能靠只报完成事件隐藏。反推完成事件的均值约为 RARE .609、context .594，
   接近正常条件 .606/.591；没有一边大量丢弃、一边靠完成事件大幅变强来维持原均值。
6. **遗忘与恢复**：旧任务固定测试集的遗忘 .025/.041；冻结 prior 期望参数遗忘
   为 0。恢复指新分布性能恢复到冻结参照 95%，不是旧任务遗忘的倒数。
   无恢复仍计 20 的受限平均，不排除失败。修正/replay 改善恢复但增加积压。
7. **安全**：放弃 v4 无依据的覆盖率 .08。显式设置同一 oracle-truth 母体的
   五种 mutation 权重，并由它计算 aggregate。UNKNOWN precision 按各层 UNKNOWN
   质量加权，等于 .4777/.498=.9592369。oracle 能判断 owner，不代表 permitted
   输入完整；precision 的真值是“公开证据是否足以支持决断”。
   同信息主基线复用同一责任门，所以同一安全测试两者应相等，不制造安全优势。
   去掉门才是责任机制对照；声称错误与非法参数更新是不同事件。

## 误差与跨表关系

主质量差主观范围 [-.016,.056]，成本差 [.05,.19]；两者的保守矩形传播得到
效用差 [-.035,.051]。没假定二者独立、没从期望显著性倒推 SD。
四格边际主观范围传播得到交互 [-.194,.196]，没有伪造一个狭窄交互 CI。
这些范围不含 95% 概率承诺；实际实验必须从独立流和预注册统计法估计真实 CI，
不能把这些范围当成接受/剔除样本的门槛。
